# fl_pi_llm

The LLM layer shared by [GPT Box](https://github.com/lollipopkit/flutter_gpt_box)
and [Server Box](https://github.com/lollipopkit/flutter_server_box).

| Package | What |
|---|---|
| [`fl_pi_llm/`](fl_pi_llm) | pi-durable and pi-ai on QuickJS, for Flutter apps and Rust programs. Published on pub.dev. |
| [`fl_pi_llm_ui/`](fl_pi_llm_ui) | Chats, tools and provider settings on it, for apps built on fl_lib. Not published. |
